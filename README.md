# 🚗 Drive Wise — Metadata-Aware Automotive RAG

Drive Wise is an AI-powered automotive assistant that answers questions about car brochures using **Retrieval-Augmented Generation (RAG)** with Google Gemini.

## Features
- 📄 **PDF Brochure Indexing** — Upload and index car brochures
- 🔍 **Hybrid Retrieval** — Semantic + keyword search
- 🤖 **Grounded Answers** — Citations from brochure pages
- 📊 **Analytics Dashboard** — LLM-as-a-judge quality scoring

## Setup
Set your `GOOGLE_API_KEY` in the Space secrets settings.
